# Coaching Site

A lightweight, mobile-friendly one-page website for coaching classes and YouTube
videos. No build tools — just HTML, CSS and JavaScript.

## Contents

- `index.html` — the page
- `assets/css/style.css` — styling
- `assets/js/main.js` — nav toggle, WhatsApp links, video pop-up, course cards
- `assets/img/` — photos and icons

## Deploy

Publish the repository to GitHub Pages (Settings → Pages → Deploy from a
branch, `main` branch, `/ (root)` folder).
